# IEEE Computer Society Global Student Challenge 2026

> Building, learning, researching, and documenting my journey through the IEEE Computer Society Global Student Challenge 2026.

## About This Repository

This repository contains my complete preparation, research, implementations, experiments, and documentation for all three challenge tracks of the IEEE Computer Society Global Student Challenge 2026.

My goal is not only to submit competitive solutions but also to document the entire learning process—from beginner-level understanding to working prototypes and final submissions.

**Competition Duration:** June 7, 2026 → August 9, 2026
**Study Commitment:** 2–4 hours/day
**Total Duration:** 63 Days (9 Weeks)

---

## Challenge Topics

### 🔒 Topic 1: Backdoor Attacks in Distributed Machine Learning

Researching how attackers can inject hidden malicious behaviors into distributed and federated machine learning systems and exploring methods to detect and mitigate such attacks.

### ⚙️ Topic 2: Automatic Discovery of Vulnerabilities in GitHub CI/CD Workflows

Building a tool that automatically analyzes GitHub Actions workflows, detects security vulnerabilities, and suggests patches.

**Primary Focus Project**

### 📊 Topic 3: Data Center Resource Analysis & Failure Prediction

Analyzing resource utilization data from large-scale computing systems and building models to predict failures and performance degradation.
